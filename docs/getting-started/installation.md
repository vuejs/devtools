## Notice

:::warning Compatibility Note
Vue DevTools only supports Vue 3. If you are using Vue 2, use [vue-devtools](https://devtools-v6.vuejs.org/) instead.
:::

:::tip Recommendation
If you are using Nuxt, use [nuxt-devtools](https://github.com/nuxt/devtools) for a more powerful developer experience.
:::
