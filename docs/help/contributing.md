# Contribution Guide

> Hi! We're really excited that you're interested in contributing to Vue DevTools! Before submitting your contribution, please read through the following guide.

## Development Setup

You will need [Node.js](https://nodejs.org) **version 22.12+** and [pnpm](https://pnpm.io) **version 12.5.1**.

We also recommend [@antfu/ni](https://github.com/antfu/ni) for switching between repositories that use different package managers. Its `nr` command makes it easier to run package scripts.

After cloning the repo, run:

```bash
pnpm i # install the dependencies of the project
```

## Development

Build the project in watch mode:

```sh
pnpm dev
```

Or build it once:

```sh
pnpm build
```

Then run the playground:

```sh
pnpm play
```

## Contributing

Please feel free to submit pull requests for bug fixes. **If you have any new ideas or feature requests, please open an issue or discussion first**.
